# Changelog

## 0.1.0 — 2026-11-25

- Added an installable, dependency-free Python inventory toolkit.
- Added safety stock, reorder point and inventory turnover calculations with documented assumptions and input validation.
- Added reference examples, boundary tests and GitHub Actions checks for Python 3.10–3.13.
- Added MIT licensing for original software and contribution guidelines.
- Preserved the Olist ELT pipeline, published Tableau dashboards, previews and dataset attribution as a worked case study.
